# 데이터에 묻는 창 — 4주차 목업

## 쓰기 전에 («내 파일로» 탭)

- **파일 이름**에 «상담내역»(→ support_tickets) · «고객목록»(→ customers) · «상담원목록»(→ agents) 가운데 하나가 **들어 있어야** 합니다. 없으면 ✕ 로 거절되고, 이 세 표 말고는 바꿀 수 없습니다.
- **첫 시트만** 읽고, 그 시트의 **첫 줄을 열 이름**으로 씁니다. 시트가 여럿이면 경고만 뜨고 나머지는 읽지 않습니다. CSV는 UTF-8만 읽습니다.
- 파일마다 «파일에서 읽은 줄»과 «표에 올라간 줄»이 같을 때만 ✓ 입니다. 다르면 ✕ 이니 그 표로 묻지 마십시오.
- 질문 옆 «확인할 값»(✓ · ✕)은 **목업 데이터(`data/`의 parquet)** 기준입니다. 내 파일을 쓰는 질문은 숫자가 달라도 되고, 그때의 ✕ 는 오류가 아닙니다.
- 파일은 **이 브라우저 안에서만** 읽히고, 코드에 파일을 서버로 보내는 곳이 없습니다. 새로고침하면 목업 데이터로 돌아갑니다. «문장으로 묻기(AI)»만 질문 문장과 표 설명을 서버로 보냅니다.
- 추출 파일은 1월부터 그달 말까지의 누적입니다. 11월 말 파일의 이탈률은 «1~11월 누적»입니다.

질문을 고르거나 쓰면 **SQL**이 돌고 표가 뜹니다. **모든 답 옆에 SQL이 있습니다.**
데이터베이스(DuckDB)는 **브라우저 안**에서 돕니다. 서버에 데이터베이스가 없습니다.

## 돌려보기

```
python -m http.server 8000
```

처음 열 때 데이터 엔진(DuckDB-WASM)을 jsdelivr 에서 받습니다. 표는 SQL에 나올 때 그 표만 받습니다.

## 올리기

```
1. 이 폴더를 내 GitHub 저장소로 (data/ 의 parquet 12개, 약 12MB 포함)
2. vercel.com → Add New → Project → Import → Application Preset: Other → Deploy
3. (선택) Settings → Environment Variables → GEMINI_API_KEY — «문장으로 묻기»가 켜집니다
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `questions.json` | ★ **준비한 질문** — 질문 · 판단 포인트 · SQL · 확인할 값(실측결과.md). **사람이 골랐다** |
| `schema.json` | 표 설명 — **한 줄이 무엇인지(그레인)** · 열 · 값 목록. `tools/make_schema.py` 로 만든다 |
| `app.js` | DuckDB-WASM 실행 · 읽기 전용 검사 · 결과표 · 막대 · «내 파일로» |
| `lib/` | 엑셀을 읽는 SheetJS (다른 사이트에서 불러오지 않는다 · 라이선스 Apache 2.0) |
| `api/sql.py` | 문장 → SQL (Gemini). **실행하지 않고 SQL만 돌려준다.** 읽기가 아니면 돌려주지 않는다 |
| `data/*.parquet` | 통신사 가상 데이터 12표 |
| `tools/verify_sql.py` | 준비한 질문을 파이썬 DuckDB로 검산 (배포 제외) |

## 내 파일로

시스템에서 내려받은 엑셀 · CSV를 «내 파일로» 탭에 넣으면, 그 파일이 같은 이름의 표를 대신합니다.
어느 파일이 어느 표인지는 `questions.json` 의 `files` 가 정합니다(파일 이름에 `match` 가 들어 있으면 그 `table`).
파일은 브라우저 안에서만 읽습니다. 넣은 뒤 나가는 요청은 없습니다.

견본: `20_데이터/generate_exports.py` → `상담내역_2025-11말.xlsx` · `상담내역_2025-12말.xlsx` · `고객목록_…` · `상담원목록.xlsx`.
12월 말 파일은 `data/` 의 parquet 과 같은 숫자를, 11월 말 파일은 11월 30일까지의 숫자를 냅니다.

## 지키는 것

- **읽기만 합니다.** SELECT · WITH 로 시작하는 한 문장만 실행합니다. AI가 쓴 SQL도, 사람이 쓴 SQL도 같은 검사를 거칩니다
- **AI에게는 질문 문장과 표 설명만** 보냅니다. 데이터는 보내지 않습니다
- AI가 쓴 SQL은 실행 전에 읽고, **결과 하나는 손으로 검산**합니다

## 확인한 숫자

```
python tools/verify_sql.py
```

준비한 질문 9개 · 확인할 값 18개 전부 실측결과와 같습니다.
